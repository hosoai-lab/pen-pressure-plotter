# 筆圧キャンバス (Pen Pressure Canvas)

Wacom などのペンタブレットで描いた線を、**筆圧に応じた色**で表示するお絵かきアプリです。
筆圧つきの軌跡を **CSV / JSON / G-code** として書き出せるので、ペンプロッタで筆圧を再現する用途を想定しています。

Python + PySide6 (Qt 6) 製で、Windows での利用を想定しています。

## 機能

- ペンの筆圧・位置・傾き (X/Y) を取得して、ステータスバーに表示
- 筆圧を色で描画 (HSV: 筆圧 0.0 = 青 → 1.0 = 赤、またはグレースケール)
- 筆圧で線の太さも変えるオプション
- 取り消し (Ctrl+Z)、全消去、PNG 保存
- 全サンプルを CSV / JSON で保存
- G-code 出力 (機器サイズ・Z 範囲・分割の粒度・補間方法を設定可能、プレビュー付き)
- タブレットが無い環境でも、マウス (筆圧 0.5 固定) で動作確認可能

## 必要なもの

- Python 3.10 以上
- PySide6

```
pip install PySide6
```

## 使い方

`pen_pressure_canvas.py` と `gcode_export.py` を同じフォルダに置いて実行します。

```
python pen_pressure_canvas.py
```

筆圧が取得できない場合は、Wacom ドライバの設定で **Windows Ink を使用する** がオンになっているか確認してください。

## 色と筆圧の対応

HSV で S = V = 1 を固定し、色相だけを筆圧に割り当てています。

| 筆圧 | 0.00 | 0.25 | 0.50 | 0.75 | 1.00 |
|---|---|---|---|---|---|
| 色相 (H) | 240° (青) | 180° | 120° | 60° | 0° (赤) |

色から筆圧を逆算できます: `pressure = 1 - H / 240`

グレースケールは薄い筆圧がほとんど見えなくなるため、HSV を推奨します。

## データの書き出し

「CSV/JSON保存…」で、描いた全サンプルを保存できます。PNG は色がアンチエイリアスで混ざるため、筆圧の元データには CSV / JSON を使ってください。

CSV の列:

| 列 | 内容 |
|---|---|
| stroke | ストローク番号 (ペンを下ろしてから上げるまでが 1 本) |
| t_ms | ストローク開始からの経過時間 (ms) |
| x_px, y_px | キャンバス上の座標 (左上原点、px) |
| pressure | 筆圧 (0.0 〜 1.0) |
| xtilt_deg, ytilt_deg | ペンの傾き (度) |

筆圧 0 のサンプル (ペンが触れていない間) は記録されません。

## G-code 出力

「G-code出力…」を押すと設定ダイアログが開きます。設定を変えると、右側の軌跡プレビューと統計 (行数、描画距離、概算時間、Z 範囲) がすぐ更新されます。設定は `~/.pen_pressure_canvas_gcode.json` に保存され、次回も引き継がれます。

| 設定 | 内容 |
|---|---|
| 機器と配置 | X 幅・Y 幅 (mm)、原点オフセット、余白。キャンバス全体を余白を除いた領域に写像します。縦横比を保って収める / 縦横それぞれ引き伸ばす、画面の上を +Y にする、を選べます。 |
| Z 軸 | ペン上げ位置、最小筆圧の Z (接地)、最大筆圧の Z (押し込み)。筆圧は線形に Z へ変換します。筆圧を Z に反映しない設定や、筆圧の有効範囲の指定もできます。 |
| 分割と補間 | 点間隔 (mm) ごとに制御点を取り直します。補間は直線、または Catmull-Rom 曲線 (1 区間を指定本数の G1 に分割) から選べます。 |
| 送り速度 | 描画 / 移動 / Z 上下 (mm/min) |
| 出力 | 小数桁数、開始コード、終了コード |

出力は G0 / G1 だけで構成され、ストロークごとに「ペン上げ移動 → ペン下ろし → 筆圧つきの G1 連続 → ペン上げ」の順に並びます。

**実機で使う前に**

- Z 軸の向きや値は機器ごとに異なります。既定値 (ペン上げ 3 mm、接地 0 mm、押し込み -1 mm) は仮のものです。紙の上で小さい範囲から試してください。
- 画面全体を機器に写すため、縦横比を保つ設定ではウィンドウサイズによってスケールが変わります。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `pen_pressure_canvas.py` | アプリ本体 (キャンバス、UI、G-code 設定ダイアログ) |
| `gcode_export.py` | G-code 変換ロジック (GUI 非依存) |

## 動作確認の状況

描画、色変換、CSV / JSON 出力、G-code 変換は、疑似ストロークを使った自動テストで確認しています。Wacom タブレットの実機入力と、ペンプロッタの実機動作は未確認です。
